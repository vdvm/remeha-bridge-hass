# Remeha Bridge

Shows your Remeha boiler and eTwist thermostat in Home Assistant, read from
the Remeha Home cloud. Read-only: the app never changes a setting.

## Installation in Home Assistant

1. In Home Assistant, navigate to **Settings** → **Apps** → **App Store**.
2. Click the three dots in the top right corner and select **Repositories**.
3. Add repository URL: `https://github.com/vdvm/remeha-bridge-hass`
4. Install **Remeha Bridge**, fill in the configuration and start it.
